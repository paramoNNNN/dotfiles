# Archive

The `work-archive-notes` timer moves dated Daily and Briefings notes from the
previous Saturday through Friday here every Saturday at 00:15 Tehran time.
Paths use `YYYY-MM/Daily/...` and `YYYY-MM/Briefings/...`; the folder level
prevents identically dated notes from overwriting each other. Different copies
are retained beneath `YYYY-MM/Conflicts/<sha256>/` for manual reconciliation.
