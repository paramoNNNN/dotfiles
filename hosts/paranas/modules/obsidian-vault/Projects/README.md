# Projects

Use `Templates/Weekend Project.md` for the context of a hobby project and
`Templates/Weekend Project Board.md` for its work items. Give the pair matching
names, for example:

```text
Projects/Offline Mode Experiment.md
Projects/Offline Mode Experiment Board.md
```

When creating the board, replace `PROJECT NAME` in its frontmatter with the
project page name (`Offline Mode Experiment` in this example). The project page
then embeds that board, so Summary, Raw notes, and the Kanban view are available
from one page while remaining separate Markdown files.

Use the board columns as follows:

- **Backlog:** possible work, without a commitment.
- **Next:** selected and ready to begin.
- **In progress:** currently being worked on; keep this small.
- **Blocked:** waiting for a decision or dependency.
- **Done:** completed work and experiments.

Use task checkboxes for board cards that should appear in vault-wide Tasks
queries. Keep observations and ideas as normal bullets in the project page.
